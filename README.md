# Salary Caps: Are They Effective?

## Overview
This project analyzes whether salary caps improve competitive balance in professional sports leagues. Using historical league data, we evaluate changes in parity, team performance dispersion, and long-term competitiveness following the introduction of salary cap policies.

## Methods
- Descriptive statistical analysis
- Competitive balance metrics (variance, dispersion measures)
- Historical comparison before and after salary cap implementation

## Code
This repository includes the R scripts and R Markdown file used to clean the data,
compute competitive balance metrics, and generate the analysis.
